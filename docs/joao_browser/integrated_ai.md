# Browser-integrated AI policy

Joao Browser builds with `ENABLE_BROWSER_INTEGRATED_AI=false`, generated by
`//build:branding_buildflags`. There is no runtime preference or Finch override
for this product policy. Chromium source, strings and feature flag definitions
are retained for upstream maintenance; runtime flags cannot bypass the guarded
eligibility boundaries.

## Disabled surfaces and services

- AI Mode: omnibox button, generic AI entry points, third-party AI button,
  new-tab composebox, contextual tools, Lens AI searchbox/M3, and eligibility
  network requests (including explicit refresh and startup requests).
- Built-in `@gemini` and `@aimode` keyword suggestions, including persisted
  starter-pack engines. The generated keyword records may remain in profile
  storage; they cannot provide keyword matches through KeywordProvider.
- Gemini/Glic: global and profile eligibility, pinned button, anchored entry
  point, launcher eligibility and settings visibility.
- Compose, history embeddings/answers and generative feature opt-ins/settings.
  Wallpaper generation is gated by this same generative-feature controller.
- Contextual task side-panel and tab-sharing eligibility, including forced
  entry-point debugging flags; contextual-cueing service creation.
- Indigo image generation eligibility and Autofill AI actions, including
  saved-data and enterprise/feature-flag bypass paths.
- AI-assisted automatic password changing. Ordinary password saving, password
  generation, filling and leak detection are unchanged.
- The AI settings page and its feature controls, including force-available
  experimental settings.

The Windows browser tree in this revision has no separate tab-organization
implementation to remove. Existing model capability enums for other platforms
are retained.

## Preserved behavior

Ordinary search/navigation, user-defined site-search engines, website contents,
web-exposed AI APIs, translation, accessibility, traditional Lens image search,
and non-generative safety/optimization services are unchanged. This is not a
ban on navigating to an AI website. Model infrastructure shared with web APIs
and safety features is not removed or globally disabled.

## Verification

Executed in this source-only Linux checkout:

- Chromium's `build/write_buildflag_header.py` generated a header containing
  `BUILDFLAG_INTERNAL_ENABLE_BROWSER_INTEGRATED_AI() (0)`.
- Pinned clang-format checks on all modified C++ files.
- Pinned `gn format --dry-run` on all modified BUILD.gn files.
- `git diff --check` on the owned files.

Added executable regressions (not run here; synced Chromium build dependencies
and a Windows x64 toolchain are required):

- `JoaoBrowserAimPolicyTest.*`: enabled runtime flags, permissive prefs and a
  positive cached eligibility response cannot enable AI Mode; manual refresh
  sends no eligibility request.
- `JoaoBrowserGlicPolicyTest.*`: enabled Gemini flags and anchored-entry settings
  cannot expose Gemini.
- `JoaoBrowserContextualTasksPolicyTest.*`: side-panel runtime overrides cannot
  enable contextual-task UI.
- `JoaoBrowserGenerativePolicyTest.*`: signed-in state, feature flags and saved
  opt-ins cannot enable Compose, wallpaper generation or history AI settings.
- `AutofillAiPermissionUtilsTest.JoaoBrowserDisablesAiWithExistingData`: existing
  entity data and enabled Autofill AI configuration cannot permit AI actions.

Run the new component tests in `components_unittests` and the Glic test in
`unit_tests`. Also run a Windows browser smoke test covering the location-bar
accessible name, new tab, context menus, AI settings deep links, a previously
AI-enabled profile, and `--enable-features` overrides.

The directly affected upstream enabled-AI fixtures explicitly skip 71 tests
in this product configuration: 39 AimEligibilityServiceTest, 15 GlicEnablingTest
and 17 ModelExecutionFeaturesControllerTest cases. Their setup is shared with
separate, executing product-policy tests. Other upstream suites assume enabled
AI (including Compose, Autofill AI and dependent Glic/Lens browser tests); they
have not been run or comprehensively adapted. No full-suite or runtime pass is
claimed. New upstream AI entry points must be reviewed against this policy.
